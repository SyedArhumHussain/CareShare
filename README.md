**CareShare – Smart Medicine Donation & Healthcare Assistance Platform**

---

## 📖 Project Description

CareShare is a **web-based healthcare platform** designed to **connect medicine donors with people in need**, reducing medical waste and improving access to essential healthcare resources.

The system integrates **Artificial Intelligence (AI)** technologies such as **OCR (Optical Character Recognition)** and **chatbot assistants** to ensure safe, efficient, and intelligent medicine distribution.

Unused medicines are a major global issue, and CareShare solves this by enabling users to **donate, verify, and receive medicines** in a secure and transparent way.

## 🚀 Key Features

### 👤 User Roles

* **Donor**

  * Upload medicines for donation
  * Add expiry date, quantity, and details
* **Receiver**

  * Search and request medicines
  * Upload prescriptions for verification
* **Admin**

  * Monitor platform
  * Approve/reject donations
  * Manage users

---

### 📄 OCR-Based Prescription Verification

* Users upload prescription images
* System extracts:

  * Medicine name
  * Dosage
  * Quantity
* Reduces manual errors and speeds up processing ([GitLab][1])

➡️ OCR helps convert handwritten prescriptions into structured data, improving efficiency and accuracy in healthcare systems ([v7labs.com][2])

---

### 📍 Location-Based Matching

* Connects donors and receivers nearby
* Uses maps/API for real-time location filtering
* Improves delivery efficiency

---

### 🤖 AI Chatbot Assistant

* Provides:

  * Basic medical guidance
  * Platform navigation help
* Built using NLP / LLM models

---

### 🔍 Medicine Search & Management

* Search medicines by:

  * Name
  * Category
* Tracks:

  * Expiry dates
  * Availability

---

### 🔐 Secure Authentication

* User login/signup
* Role-based access
* Data protection

## 🧠 System Architecture

### 🔧 High-Level Flow

1. User registers/login
2. Donor uploads medicine
3. Receiver searches medicine
4. Receiver uploads prescription
5. OCR extracts & verifies data
6. Admin approves request
7. Medicine is shared
